# Élan

Application web personnelle de minuteurs et de comptage de répétitions par caméra (pompes, squats, sit-ups) pour le sport du matin. Conçue à deux IA : Claude et ChatGPT, arbitrées par Thibaut.

## État

**Étape 0, labo** : `lab.html` mesure sur iPhone ce que Safari permet réellement (son avec Spotify, voix française, écran allumé, veille, caméra et comptage). Son rapport sert à figer les contrats de l'étape 1.

## Règles

- HTML, CSS et JavaScript en modules, sans build.
- MediaPipe Tasks Vision épinglé en version exacte (actuellement 1.0.1).
- Les images et les données d'entraînement sont traitées localement ; aucune télémétrie applicative n'est envoyée.
- Une branche et une pull request par étape, relecture croisée par l'autre IA.

## Lancer

Publié par GitHub Pages depuis la branche `main`, à la racine.
